# Beware Low-Flying Girls: Reading at Three Levels

**Suggested repository name:** `beware-low-flying-girls-reading-guide`

A self-contained reading guide for the opening extract of *Beware Low-Flying Girls* by Katherine Rundell (Cambridge Lower Secondary English 7, session 1.1 "The start of an adventure").

## Files

| File | What it is |
|---|---|
| `beware-low-flying-girls-guide.html` | The guide itself. Open this in any browser, or host it as a static page. |
| `beware-low-flying-girls-illustration.png` | The illustration shown at the top of the extract. Referenced by the guide, and can be reused on its own. |
| `beware-low-flying-girls-audio.mp3` | The read-aloud audio track for the extract. Referenced by the guide's "Read aloud" button. |

## Using it

Keep all three files in the same folder (as they are here). Opening `beware-low-flying-girls-guide.html` in a browser will pick up the illustration and audio automatically, with no build step or server required.

## Contents of the guide

- **The extract** — the full opening text, with an illustration and a "Read aloud" audio player
- **Ingredients & Recipe** — a sort activity on the features of an adventure story
- **Story order** — the extract's narrative structure, first four points given, last two revealed on request
- **Comprehension** — questions that scan for explicit information, then work out implicit information, with model answers
- **Vocabulary in context** — a match game for four words from the extract

Source: Cambridge Lower Secondary English 7 Learner's Book and Answers, session 1.1. Original material © Cambridge University Press 2021.
